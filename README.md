# 🌟 مشروع "لُب" (Lub) — استخلاص مشاريع الأكواد والرفع إلى GitHub

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) للاستخدام الشخصي المستقل، يعمل كأداة عائمة فوق أي تطبيق أو متصفح ذكاء اصطناعي (Claude, ChatGPT, Gemini, DeepSeek...) لاستخلاص "الزبدة": ملفات المشروع البرمجي الصافية فقط وتجاهل الشرح، وحفظها محلياً ورفعها بضغطة واحدة إلى مستودع GitHub جديد أو موجود بـ Commit واحد.

---

## ⚡ المبدأ الأساسي والأمان
1. **الالتقاط عند الطلب فقط**: لُب لا يقرأ الشاشة ولا يخزن أي محتوى إلا عند ضغط زر الالتقاط صراحة.
2. **لا خوادم وسيطة**: لا توجد خوادم تتبع أو إعلانات؛ الاتصال يتم مباشرة بين هاتفك و `api.github.com`.
3. **تشفير التوكن**: يُخزن رمز الوصول الخاص بـ GitHub مشفراً عبر **Android Keystore (AES-GCM)** محلياً داخل عتاد الجهاز.
4. **قائمة التطبيقات الممنوعة (DenyList)**: تختفي الفقاعة تلقائياً في تطبيقات البنوك ومديري كلمات السر وإعدادات النظام لحماية خصوصيتك.

---

## 🧭 خطوات التثبيت والإعداد الأولي (لأجهزة أندرويد 13+ و Honor)

### ١. تثبيت ملف الـ APK
- قم بتحميل ملف الـ APK وتثبيته يدوياً على هاتفك.
- اسم التطبيق يظهر كـ **"لُب"** برمز الدائرة الداكنة وحرف "ل".

### ٢. حل تنبيه "الإعدادات المقيّدة" (Restricted Settings)
على إصدارات أندرويد 13 فما فوق، تفرض أنظمة أندرويد حظراً أمنياً افتراضياً على خدمات إمكانية الوصول للتطبيقات المثبتة يدوياً من خارج المتجر:
1. افتح تطبيق **لُب**.
2. حاول الدخول لإعدادات إمكانية الوصول لتفعيل الخدمة (سيظهر لك تنبيه الحظر "تم تقييد الإعداد").
3. اذهب إلى: **إعدادات الهاتف ← التطبيقات ← إدارة التطبيقات ← لُب (معلومات التطبيق)**.
4. اضغط على **النقاط الثلاث (⋮)** أعلى يسار الشاشة.
5. اختر **«السماح بالإعدادات المقيّدة» (Allow restricted settings)**، وأدخل رمز قفل الشاشة للتأكيد.
6. عُد لتطبيق لُب وتفضّل بتفعيل الخدمة.

### ٣. ضبط البطارية وإدارة التشغيل (مهم لهواتف Honor و EMUI)
لكي لا يوقف النظام الفقاعة العائمة في الخلفية:
- افتح **معلومات تطبيق لُب ← البطارية / إدارة التشغيل**.
- عطل "الإدارة التلقائية" واجعلها **إدارة يدوية**.
- فعّل: **التشغيل التلقائي**، **التشغيل الثانوي**، و**العمل في الخلفية**.
- من شاشة التطبيقات الأخيرة (Recent Apps)، اسحب بطاقة تطبيق لُب للأسفل أو اضغط رمز القفل لتثبيته.

---

## 🚀 طريقة الاستخدام السريع (⚡ المسار السريع)

1. أثناء محادثتك مع الذكاء الاصطناعي (أو بعد كتابته للمشروع):
2. اضغط على **الفقاعة العائمة** على حافة الشاشة.
3. اختر **«⚡ التقط وارفع»** (أو "سحب المحادثة كاملة" إذا كان الكود موزعاً عبر أجزاء متتابعة).
4. يقوم "لُب" بتحليل الشاشة، إزالة أرقام الأسطر وكلمات النسخ، وتجميع الملفات في مشروع متكامل.
5. تظهر لك **ورقة التأكيد**:
   - اسم المستودع المقترح تلقائياً (من `package.json` أو ملفات المشروع).
   - الوصف المقترح تلقائياً.
   - تبديل المستودع (عام Public / خاص Private).
   - فحص الأمان واكتشاف أي مفاتيح سرية (SecretScanner).
6. اضغط **«🚀 ارفع الآن»**: يُنشأ المستودع وتُرفع كافة الملفات في ثوانٍ بـ Commit واحد وتظهر شاشة النجاح مع رابط المستودع للفتح والمشاركة!

## 📂 وظائف إضافية
- **رفع مجلد من الهاتف**: اختيار مجلد كامل عبر واجهة المستندات (SAF) مع الاستبعاد الذكي لـ `node_modules` و `build`.
- **فك ضغط الأرشيفات**: يدعم استخراج واستعراض ملفات `ZIP`, `TAR`, `TAR.GZ`, `7z` مع حماية كاملة للأسماء العربية والملفات الثنائية.
- **إضافة GitHub Actions Workflows**: إمكانية إضافة workflow جاهز لنشر GitHub Pages أو بناء ملفات APK للأندرويد بنقرة واحدة من شاشة النجاح.

---

## 📦 بناء الـ APK عبر GitHub Actions
يحتوي المشروع على ملف جاهز تحت مسار `.github/workflows/build-apk.yml`.
1. ارفع المشروع إلى مستودعك الخاص على GitHub.
2. توجه لتبويب **Actions**.
3. اختر سير العمل **"Build Lub APK"** واضغط **Run workflow**.
4. بعد اكتمال البناء، ستجد ملف الـ APK جاهزاً للتحميل في قسم **Artifacts**.
